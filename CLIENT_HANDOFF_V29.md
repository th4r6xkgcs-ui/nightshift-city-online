# Visual foundation pass — v0.29

Branch codex/visual-foundation-v29, stacked on codex/encounter-quality-v28. Reserved client art files through Claude PR #3. Online/server/shared/worker/workflows remain Claude-owned and unchanged. No gameplay additions, collision/catalog edits, economy/save migrations or PR merges.

Rebuilt world.js presentation: deterministic asphalt grain/patches, double lane stripes, proper crossing approaches, stop lines, tiled sidewalks/curbs, drains/manholes, parking bays, planters/trees, benches and bins. Previously empty West End blocks gain a marked basketball court and pocket plazas. A single 2200x1700 ground canvas is generated once and reused across frames (roughly 15 MB RGBA); no random texture generation per frame. Environments without a canvas factory use the direct renderer fallback. Buildings outside the viewport are culled. Existing building footprints/entrances remain exactly the catalog's values; cosmetic street props are not new collision obstacles.

Architecture now has south-facing brick facades, raised/parapeted roof edges, cast shadows, distinct corrugated industrial roofs/skylights, commercial roof utilities, apartment water tanks, front doors/shutters, window frames/sills, awnings and storefront signs. Warm nighttime windows and lamps add depth; lamp posts remain visible by day. All neighborhoods share this initial visual vocabulary, with industrial/storefront/apartment/club differences rather than changing geometry. This is a procedural art foundation, not final bespoke texture/sprite packs.

Shared vehicle renderer distinguishes compact tapered body/cabin, sedan trunk/hood and van cargo roof; adds tire/rim motion, mirrors, glass highlights, body shading, lamps, player brake lights and condition-based scars. Body silhouettes stay within existing vehicle dimensions (cosmetic shadows/mirrors extend slightly). Shared characters gain eight facing poses, layered jackets/zippers/hem, hair/face variations, directional caps/bags, four-frame moving gait and stationary idle. Existing profile colors and weapon hiding indoors are retained. Pixel image smoothing is disabled for the world layer. No new weather, steering animation or animation asset sheet is claimed.

Touched: world.js, sprite-renderer.js, environment.js, game.js, index.html, package.json, tests/render.cjs, tests/visual-foundation.cjs and tests/run.cjs. Shared docs remain separate to avoid concurrent edits.

Validation: npm run check passes 55 suites plus all root syntax; git diff --check passes. New renderer checks verify cached-ground reuse, deterministic texture, all eight facing directions, idle/walking cycle, distinct model details and no writes to player/vehicle/pedestrian/building state. Existing collision/AI/controls/combat/economy/save tests pass. Internal Canvas scenes inspected at 390x844 for West End evening, Midtown day and Docks evening; these do not test DOM/dual-touch or establish iPhone FPS. Real browser/iPhone performance/audio/touch QA remains pending. Build retains 47 playable assets and adds no runtime dependencies.

Release pending: draft PR and existing private preview publication. Next art work should be judged from the playable view/device feedback: bespoke neighborhood architecture, actual sprite animations and lighting polish, rather than more gameplay menus.
