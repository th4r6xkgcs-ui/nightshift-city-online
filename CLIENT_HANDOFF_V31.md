# Runtime character atlases and storefront depth — v0.31

Branch codex/animation-art-v31, stacked on codex/landmark-art-v30 (draft PR #15). Reserved client sprite/world/test/version scope through Claude PR #3. Online/server/shared/worker/workflows unchanged; client PR stack stays draft/unmerged.

Incoming v0.30 failed tests/visual-foundation.cjs because the new assertion read player/cars/peds/buildings directly in Node rather than through the VM harness. Corrected that read and verified its architecture rendering checks with the full suite. The previously undeployed landmark/weathering pass is included in this release.

Characters now draw from runtime-generated sprite atlases: 8 facing rows × 8 walk frames, 48×52 cells, 384×416 pixels per palette/profile atlas. A bounded eight-entry LRU retains at most about 4.9 MiB RGBA character art in addition to the existing ground cache. Repeated body draws blit cached cells rather than rebuild each pixel. Profile skin/hair/shirt/pants/shoes/hat/bag changes choose a different atlas; idle uses frame zero. Movement uses a smoother eight-frame gait; invalid or negative walk counters normalize safely. Dynamic weapons and damaged-NPC health bars remain separate, and indoor weapon hiding remains respected. Canvas-less test environments retain direct rendering fallback. These are procedurally generated game-native sheets, not commissioned/bespoke sprite assets or external downloads.

Car art: compact cabin/hatch and hood proportions tightened, sedan hood contours refined, van cargo panels/seams added. Collision footprints and handling unchanged. Indoor shelves, counter/register, bed/pillows, sofa cushions, kitchen and cabinets also gain shared pixel furniture art; room coordinates/collision/interaction behavior remain unchanged. Storefronts now include shaded recessed displays, clothing mannequins, diner booths/tables, shop shelf merchandise, glass glints and small threshold steps. These details are cosmetic; no new collisions or gameplay. Runtime renderer never writes player/NPC/vehicle/building state.

Touched: sprite-renderer.js, world.js, home.js, game.js, index.html, package.json, tests/visual-foundation.cjs, tests/sprite-atlas.cjs and tests/run.cjs. Separate handoff avoids shared-document conflicts.

Validation: npm run check passes 56 suites and root syntax; git diff --check passes. New tests check actual drawImage cell selection/cache reuse, all eight frames/directional rows, stationary pose, invalid counters, LRU bound, profile changes and gameplay-state preservation. Existing combat, AI, physics, input, economy/custody and persistence regressions pass. Canvas renders inspected at 390×844 for West End, Midtown/day and shop interior. Real browser/iPhone DOM/touch/performance QA is still pending; no FPS benchmark claimed. Build retains 47 playable assets, no dependencies, geometry/economy/save format changes.
